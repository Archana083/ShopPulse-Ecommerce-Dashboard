# ShopPulse — E-commerce Analytics & Management Dashboard

A portfolio-grade Vue 3 + TypeScript admin dashboard focused on large-data workflows, analytics, reusable components, filtering, and business logic.

## Stack
- Vue 3 + Composition API
- TypeScript
- Pinia
- Vue Router
- Tailwind CSS
- Vite

## Data architecture
UI → Pinia store → service layer → JSON mock API

The initial dataset includes products, customers, orders, and categories.
